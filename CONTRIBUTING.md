# Contributing

PRs welcome. To add an entry:

1. Put it under the right region in **Cities**, or in **Other maps, games and racing** if it isn't a city sim.
2. Keep entries alphabetical within a section. Name cities as **City, Country**; add a short tag in brackets to tell apart several takes on one city, e.g. **Taipei, Taiwan (sc0Vu)**.
3. Use this format (drop any link you don't have):

   ```markdown
   - **City, Country** - [Play](https://...) · [Source](https://github.com/...) · [Tweet](https://x.com/...) - by [@handle](https://x.com/handle). One-line description.
   ```

4. Strip tracking params like `?s=20` from tweet links.
5. Link only to things that load. Mark anything you couldn't check as *(unverified)*.
